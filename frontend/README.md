# Flipkart Customer Care Chatbot - Frontend

Next.js frontend for the AI-powered customer support chatbot.

## Setup

```bash
npm install
npm run dev
```

Frontend runs on `http://localhost:3000` and connects to backend at `http://localhost:8000`.

## Features

- Multi-threaded chat conversations with persistent history
- WebSocket and HTTP streaming for real-time token streaming
- Sidebar thread management (create, select, rename, delete)
- Source attribution for RAG-retrieved documents
- Responsive UI with Tailwind CSS
